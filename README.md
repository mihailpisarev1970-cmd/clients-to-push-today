# Clients To Push Today — приоритизация клиентов из выгрузки сделок

**Clients To Push Today** — веб-приложение на Python для менеджера отдела продаж: загружаете выгрузку клиентов из CRM (CSV или Excel) либо вставляете ссылку на документ — и за секунду получаете список из **пяти клиентов, с которыми нужно работать именно сегодня**, в порядке приоритета и с конкретным действием по каждому.

Это не «красивый дашборд», а рабочий инструмент для ежедневного ритма продаж: утром у менеджера десятки открытых сделок, а реально «дожать» он успевает пять. Программа сама разбирает этапы, суммы, даты следующих шагов и комментарии менеджера, применяет правила компании и выдаёт готовый план на день — без ручного перебора таблицы и без вызовов нейросети в момент работы.

## Задача, которую решает проект

- Сократить время утреннего планирования: вместо просмотра 40+ строк выгрузки — готовые 5 приоритетов.
- Не потерять деньги: сначала поднимаются сделки, где оплата или решение клиента ближе всего.
- Соблюдать регламент: 100% предоплата для юрлиц и физлиц, скидка до 7% без согласования, счёт действует 5 рабочих дней, ЛПР — руководитель или владелец (для бюджетных учреждений договор готовит завхоз).
- Отсечь «мусор»: дубли сделок, клиенты у конкурентов, неверные номера, «вернёмся позже», отложенные на месяцы задачи.
- Честно сообщать о неопределённости: если следующего шага нет или срок явно прошёл, программа пишет «не уверен, что делать», а не выдумывает действие.

## Как работает выбор клиентов

Алгоритм детерминированный — решения принимаются по правилам и признакам в комментариях, без LLM в рантайме:

1. **Отсев неактуальных.** Убираются сделки с пометками «купили у конкурента», «номер неверный», «вернёмся позже», бюджет следующего года, а также задачи с датой дальше чем через 14 дней.
2. **Дедупликация.** Одинаковые клиент + товар схлопываются; остаётся свежая сделка с пометкой про дубль.
3. **Приоритет по скорости денег.** Выше всех: просят выставить счёт, поступила оплата, просят пересчитать КП, нужен проект договора для бюджетника, клиент готов купить, идёт согласование с ЛПР, назначен созвон.
4. **Проверка правил компании.** Отсрочка физлицу помечается как нарушение (предлагается 100% предоплата), скидка больше 7% — только после согласования с руководителем, просроченный счёт — перевыставить.
5. **Вторичный ключ.** Сумма сделки (вклад в план) и свежесть последнего контакта.
6. **Формат ответа.** Пять пронумерованных сделок с клиентом, суммой, действием на сегодня и датой следующего шага; последняя строка — `Итог: номер, номер, …`.

## Возможности

- загрузка файла `.csv` (выгрузка листа «Сделки») или `.xlsx` (исходная книга — лист находится автоматически);
- ввод ссылки на документ: прямые http/https-ссылки на CSV/XLSX и Google Sheets (ссылка `/edit` сама превращается в экспорт CSV); ссылка имеет приоритет над файлом;
- поле «Сегодня» с датой по умолчанию и возможностью указать свою; пустое значение = текущая дата;
- устойчивый парсер: русские и английские заголовки, BOM, разные разделители и форматы дат, числа с пробелами и «₽»;
- проверка срока действия счёта — 5 рабочих дней с учётом выходных;
- контейнеризация, healthcheck, reverse-proxy на Nginx и HTTPS с автопродлением сертификата;
- 12 юнит-тестов на парсинг, приоритеты, дубли, «мёртвые» сделки, загрузку по ссылке и формат ответа.

## Стек

Python 3.11+, Gradio 6, pandas, openpyxl, python-dateutil, pytest, Docker, Docker Compose, Nginx, Certbot / Let's Encrypt.

## Установка и локальный запуск

```bash
git clone https://github.com/mihailpisarev1970-cmd/clients-to-push-today.git
cd clients-to-push-today
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m pytest tests -q
python app/app.py              # http://localhost:7860
```

## Деплой на VPS

В репозитории есть `deploy/docker-compose.yml` и `deploy/setup-server.sh`. Скрипт ставит Docker (если нужно), поднимает контейнер с именем `perfect_pull-up`, настраивает Nginx на ваш домен и выпускает сертификат Let's Encrypt с автообновлением через `certbot.timer`. Секреты и адреса серверов в репозиторий не включены — передавайте их через переменные окружения и свои конфиги.

## Для кого полезно

Менеджеры по продажам, руководители отделов продаж, бизнес-ассистенты и CRM-администраторы, которым нужно каждый день быстро отвечать на вопрос: «каких клиентов дожимать сегодня и что именно сделать по каждому?». Проект также показывает, как превратить разрозненные комментарии в CRM в воспроизводимое правило ранжирования без зависимости от внешних LLM.
